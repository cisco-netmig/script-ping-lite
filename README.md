# Ping Lite

## Overview
**Ping Lite** is a lightweight tool used to monitor host reachability by continuously pinging IP addresses or hostnames.

## Features
- Supports individual IPs, hostnames, and subnets.
- Displays real-time packet loss, round-trip time (RTT), and reachability status.
- Uses a multi-threaded approach for faster results.
- Provides a graphical interface for managing and monitoring hosts.

## Usage
- Enter individual IPs, hostnames, or subnets.
- The tool continuously pings the entered addresses.  
- Green indicates a reachable host, while red indicates an unreachable host.
- Check **sent, received, lost packets, RTT**, and thread status.
